## ✨Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- [React Native](https://reactnative.dev/) – framework principal para desenvolvimento mobile
- [TypeScript](https://www.typescriptlang.org/) – tipagem estática para JavaScript
- [Expo](https://expo.dev/) – facilita build, desenvolvimento e deploy do app
- [React Navigation](https://reactnavigation.org/) – gerenciamento de rotas e navegação
- [Day.js](https://day.js.org/) – manipulação de datas
- [UUID](https://www.npmjs.com/package/uuid) – geração de identificadores únicos
- [Gorhom Bottom Sheet](https://gorhom.github.io/react-native-bottom-sheet/) – componentes de bottom sheet
- [AsyncStorage](https://react-native-async-storage.github.io/async-storage/) – armazenamento local de dados
- [Expo Google Fonts](https://github.com/expo/google-fonts) – integração de fontes personalizadas

## 💻 Projeto

O Easybudget é um aplicativo mobile desenvolvido em React Native que permite criar, gerenciar e visualizar orçamentos de forma prática e intuitiva. O projeto possibilita adicionar serviços com quantidades e preços, aplicar descontos, duplicar orçamentos e alterar seu status dentro do ciclo de vendas (Rascunho, Enviado, Aprovado ou Recusado). Além disso, oferece filtros por status e ordenação, garantindo fácil navegação entre os orçamentos. Todos os dados são armazenados localmente no dispositivo usando AsyncStorage, permitindo persistência mesmo após o fechamento do app. A interface segue o layout fornecido no Figma, priorizando usabilidade e clareza para o usuário, com a possibilidade de expansão futura, como compartilhamento de PDF, temas customizados e histórico ilimitado.
